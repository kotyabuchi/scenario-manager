# UI-06 共通モバイルナビゲーション案

2026-09-28、未ログインの `/scenarios` を 390×844 で撮影し、ヘッダー・下部ナビ・中央メニューの通常時と展開時を比較した。After は ImageGen による検討用画像であり、実装画面は別途記録する。

実装後の同条件の画面は [通常時](implemented-mobile-default.png) と [中央メニュー展開時](implemented-mobile-actions.png) に記録した。画像生成案の本文やメニュー内容は採用せず、実際の機能と認証状態を維持した。選択中のアイコンと文字には `primary.default` を使う。下部ナビの余白はセーフエリアに加えて20px、中央ボタンの上への張り出しは8pxとする。ナビ上端の盛り上がりは見送る。

提案では、共通ナビの紙色の面、ブランドグリーン、アイコンとラベルの寸法を揃える。未ログイン時の中央操作は「作成」ではなく「メニュー」とし、展開時は「閉じる」に変える。操作一覧は下部ナビに接続して見える位置に置き、薄い背景オーバーレイで前景を明確にする。現行のゲスト向け操作項目は維持する。

ImageGen には現行キャプチャを編集対象、既存シナリオ画面を色と面の参照として渡し、本文の構成を保ったまま共通ナビのみ刷新するよう指定した。初回案で中央ボタンが「作成」になったため、未ログイン時の動作に合わせて通常時を「メニュー」、展開時を「閉じる」に修正した。`after-mobile-default.png` は初回案、`-v2.png` が比較ページで使用する案。

再生成時の指定は [prompts.md](prompts.md) に記録した。

画像生成により本文の文字・寸法に差が生じ得るため、評価対象は共通ナビのみ。実装では 390px と 320px のゲスト表示、背景オーバーレイとメニューの開閉、Escape 後のフォーカス復帰、横スクロールなしを確認した。メニュー項目は認証状態ごとにコンポーネントテストで確認した。実機のセーフエリアと認証済み画面の表示は、次の実画面確認対象とする。デスクトップの SpeedDial は今回の画像比較の対象外だが、同じ面・操作色とアクセシビリティを適用した。
