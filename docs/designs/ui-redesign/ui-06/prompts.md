# UI-06 ImageGen プロンプト

生成方法は組み込み ImageGen。現行のゲスト向け `/scenarios` の 390×844 キャプチャを編集対象とし、既存の緑基調のシナリオ画面を見た目の参照に使った。透明背景は使わない。

## 通常時の初回案

> 390×844 の現行スクリーンショットを編集対象とする。シナリオ検索の内容、カード、文字情報、スクロール位置はできる限り維持する。固定モバイルヘッダー、固定下部ナビ、中央操作だけを刷新する。紙色 `#FAFCF8` とブランドグリーン `#68A872` を基調に、やわらかな面・控えめな輪郭と影を使う。ヘッダーのロゴ・サービス名・ログイン操作を一列に整える。下部ナビはホーム、セッション、中央操作、シナリオ、マイページの5項目を維持し、44px以上のタップ領域、統一したアイコンサイズ、読める日本語ラベル、明確な選択状態を設ける。デバイス枠、注釈、透かしは付けない。

初回案の中央操作は「作成」となったが、現行ゲストメニューには作成機能がないため採用しない。

## メニュー展開時の初回案

> 現行の展開画面を操作項目の参照、通常時のAfter案をヘッダー・下部ナビ・文字・色の厳密な参照とする。中央操作を開き、下部ナビの直上に紙色の操作シートを配置する。項目は「シナリオ検索」「シェア」「ログイン」「サービスについて」の4つをそのまま保持し、緑色の一貫したアイコン、44px以上の操作領域、十分な余白を設ける。背景は薄く暗くして前景を明確にし、元の画面内容を認識できる程度に残す。中央アイコンは閉じる `×` に切り替える。390×844 内に収め、デバイス枠、注釈、透かしを付けない。

## 最終案への局所修正

- 通常時: 中央の緑の円は位置・寸法・色・影を維持し、白いプラスを白い三点メニューアイコンに、直下の「作成」を同じ書式の「メニュー」に変更する。他の画素は可能な限り維持する。
- 展開時: 中央の緑の円と `×` は維持し、直下の「作成」だけを同じ書式の「閉じる」に変更する。他の画素は可能な限り維持する。

比較ページで使用する成果物は `after-mobile-default-v2.png` と `after-mobile-actions-v2.png`。画像生成のため本文の細部は実画面と一致しないことがある。
