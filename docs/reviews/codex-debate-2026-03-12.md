## 所見

最重要の発見はサーバー側フェーズガードの欠落。現行 `updateScenarioAction` の RECRUITING/PREPARATION 制限が統合後に失われる設計だった。Action 層に「scenarioId 変更検出 → フェーズチェック」を追加することで解決。これにより、フロント側 UI 制御に加えてサーバー側でも業務ルールが保護される。
